# Student Grade Calculator
Stage 1 - Section 6

A Java console application that calculates a weighted grade from two numeric exam scores. The example weights are 40% midterm and 60% final, with a passing threshold of 60. Scores must be between 0 and 100.

## Run
```sh
javac Main.java
java Main
```
Example: 70 and 80 produce 76.00 (PASS). The program expects numeric input.
